# 1 技术文档规范

技术文档应让读者知道背景、目标、适用范围、操作步骤、限制和验证方式。标题、术语、代码块和表格保持稳定，文档中的命令应注明运行环境和风险。

## 1.1 常见文档类型

| 类型 | 核心内容 |
| :--- | :--- |
| 概念文档 | 定义、边界、原理、适用和不适用场景 |
| 操作文档 | 前置条件、步骤、配置、验证和回滚 |
| 设计文档 | 背景、目标、方案、取舍、风险和迁移 |
| 故障手册 | 症状、证据、止损、排查、恢复和升级 |
| 复盘文档 | 时间线、影响、原因、行动项和验证 |

避免只描述“是什么”而不说明“什么时候用、如何验证、失败怎么办”。示例应可运行或明确说明伪代码，链接和版本信息应定期检查。
