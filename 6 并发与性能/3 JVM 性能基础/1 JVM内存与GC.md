# 1 JVM 内存与 GC

JVM 运行时通常包含堆、线程栈、元空间、代码缓存、直接内存和本地库资源。堆用于对象分配，线程栈保存调用帧；堆外内存不受堆大小限制，但仍会消耗进程地址空间。

## 1.1 垃圾回收

GC 通过可达性分析判断对象是否仍被根引用。年轻代对象通常存活时间短，分代回收利用这一特征减少扫描成本；老年代回收和整理可能带来更长停顿。不同收集器对吞吐、延迟和内存占用的取舍不同，应基于真实负载选择。

常见问题包括堆不断增长、晋升过快、频繁 Young GC、Full GC、直接内存耗尽和元空间增长。排查需要结合 GC 日志、堆转储、类直方图、线程栈和进程级内存，而不是只调大 `-Xmx`。

## 1.2 诊断要点

- 记录 GC 次数、暂停时间、分配速率和老年代占用。
- 检查缓存、ThreadLocal、监听器和集合是否长期持有对象。
- 通过线程 dump 判断锁等待、死循环和线程泄漏。
- 使用堆转储分析对象数量、引用链和大数组。
- 保留启动参数、JDK 版本、容器内存限制和故障时间点。
