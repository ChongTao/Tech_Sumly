# 1 复杂度与线性结构

## 1.1 复杂度

时间复杂度描述输入规模增长时操作次数的增长趋势，空间复杂度描述额外内存的增长趋势。常用大 O 表示上界量级，分析时忽略常数和低阶项，但实际性能仍受缓存、分配、数据分布和实现细节影响。

| 复杂度 | 常见场景 |
| :--- | :--- |
| `O(1)` | 数组按下标访问、哈希平均查找 |
| `O(log n)` | 平衡树查找、二分查找 |
| `O(n)` | 一次扫描、线性查找 |
| `O(n log n)` | 归并排序、堆排序、平均快速排序 |
| `O(n²)` | 简单双重循环、朴素两两比较 |

分析嵌套循环时不能只看层数，还要看循环变量之间的关系；例如逐步减半的循环可能是对数复杂度。递归算法需要同时分析递推关系、调用栈和是否重复计算。

## 1.2 数组与链表

数组元素连续存储，按下标访问快且缓存局部性好；中间插入和删除通常需要移动大量元素。链表插入删除可以通过修改指针完成，但查找慢、额外指针开销大、缓存局部性差。

动态数组通过扩容获得均摊 `O(1)` 尾部追加，扩容时需要分配新空间并复制元素。容量规划应结合增长因子、内存上限和突发流量，避免频繁扩容或一次申请过大空间。

## 1.3 栈、队列与优先队列

- 栈遵循后进先出，适合函数调用、括号匹配、深度优先遍历和撤销操作。
- 队列遵循先进先出，适合任务调度、广度优先遍历和生产者消费者模型。
- 双端队列允许两端操作，可由环形数组或链表实现。
- 优先队列通常由堆实现，用于每次取出最小或最大元素。

队列用于并发系统时必须设置容量、拒绝策略和关闭语义。无限队列可能掩盖消费者变慢，最终导致延迟和内存同时增长。
