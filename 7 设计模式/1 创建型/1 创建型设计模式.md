# 1 创建型设计模式

创建型模式关注对象如何创建、组装和控制生命周期，常见模式包括工厂方法、抽象工厂、建造者、单例和原型。

## 1.1 常见模式

| 模式 | 解决的问题 | 注意事项 |
| :--- | :--- | :--- |
| 工厂方法 | 将具体对象创建延迟到子类或注册表 | 避免工厂分支无限膨胀 |
| 抽象工厂 | 创建一组相互匹配的产品 | 适合产品族，不适合只有一种产品 |
| 建造者 | 分步构建复杂对象 | 可用来保证必填字段和不可变对象 |
| 单例 | 控制某类实例数量 | 全局状态会降低测试性和并发安全性 |
| 原型 | 通过复制已有对象创建实例 | 需明确浅拷贝、深拷贝和资源句柄语义 |

依赖注入通常比业务代码主动查找单例更易测试。工厂应封装创建规则和依赖组装，不要把业务流程也塞进工厂。
