# 1 结构型设计模式

结构型模式关注对象和模块如何组合，常见模式包括适配器、装饰器、代理、外观、组合、桥接和享元。

## 1.1 常见模式

| 模式 | 作用 | 典型场景 |
| :--- | :--- | :--- |
| 适配器 | 把一个接口转换成客户端需要的接口 | 接入第三方 SDK、旧接口兼容 |
| 装饰器 | 不修改原对象而叠加行为 | 重试、缓存、日志、权限 |
| 代理 | 控制对目标对象的访问 | 远程代理、懒加载、访问控制 |
| 外观 | 为复杂子系统提供统一入口 | 门面服务、应用服务 |
| 组合 | 用树结构统一处理单对象和集合 | 菜单、目录、表达式 |

装饰器和代理都可以包裹对象，但装饰器通常强调增加可组合行为，代理强调控制访问、生命周期或远程边界。引入结构型模式前，应确认接口稳定且组合收益大于抽象成本。
