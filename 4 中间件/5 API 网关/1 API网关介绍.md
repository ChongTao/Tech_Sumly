# 1 API 网关介绍

API 网关是客户端访问后端服务的统一入口，负责路由、认证、授权、限流、协议转换、超时、观测和安全策略。它适合集中处理边界能力，但不应承载复杂业务逻辑或成为所有内部调用的单点瓶颈。

## 1.1 请求处理链路

典型链路为 TLS 终止、请求解析、身份认证、授权、限流、路由、负载均衡、超时控制、响应转换和审计。每一步都要定义失败行为和超时预算，避免网关等待下游无限期占用连接。

## 1.2 核心治理

- 路由按主机、路径、方法、版本、租户或请求头匹配，规则需要版本化和灰度能力。
- 认证确认身份，授权确认资源和动作；网关校验后，下游仍应在资源边界再次授权。
- 限流可按 IP、用户、租户、接口和全局容量设置，超限返回稳定错误码和重试提示。
- 熔断、重试和降级必须考虑幂等、总超时和下游容量，避免网关放大故障。

## 1.3 安全与观测

限制请求体、首部、上传文件和连接数，防止路径穿越、请求走私、SSRF 和恶意重定向。正确传递 trace ID、请求 ID、客户端地址和版本；日志脱敏并记录路由、状态码、耗时、重试和限流结果。

网关应部署多个实例，配置健康检查、证书轮换和规则回滚。长任务应返回任务 ID，异步结果通过查询、Webhook 或消息通知，不要让网关长期占用同步连接。
