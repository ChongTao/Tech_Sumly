# 一 OpenSearch介绍

[OpenSearch](https://docs.opensearch.org.cn/docs/latest/getting-started/intro/)是一个分布式搜索和分析引擎，源自 Elasticsearch 7.10 分支，由 AWS 主导维护。

## 1.1 基本概念

- 文档：文档是OpenSearch中最小的数据单元，使用JSON格式表示，类似关系型数据库中的“一行记录（Row），如下，其中每个文档都有一个**_id**。

  ```json
  {
    "name": "John Doe",
    "gpa": 3.89,
    "grad_year": 2022
  }
  ```

- 索引：索引是文档的集合，类似关系数据库中的表，其中索引名必须小写。

- 字段：文档中一个属性，对应JSON中的key，常见的字段包括text、keyword等。

- 映射：**Mapping 定义了索引中字段的结构和类型**，相当于数据库的“表结构”。

- 分片：OpenSearch 将索引拆分为*分片*。每个分片存储索引中所有文档的一个子集，用于集群中节点的均匀分布。

- 节点：**一个运行中的 OpenSearch 实例**，通常是一台服务器或一个容器。

## 1.2 倒排索引

- 正排索引：通过文档ID来快速找到这个文档全部内容。

- 倒排索引：倒排索引是搜索引擎的核心数据结构，本质是将文档集合按“词”进行反向组织，使查询由文档扫描转变为集合求交运算，从而支持高性能全文检索与相关度排序。
